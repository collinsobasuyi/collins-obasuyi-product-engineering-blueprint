# {{PROJECT_NAME}} — UX Principles

## Purpose

Define the experience principles that guide product design decisions.

## Principles

### 1. Clarity first

Users should understand what the system is doing and what happens next.

### 2. Reduce unnecessary effort

Critical journeys should minimise avoidable steps and cognitive load.

### 3. Preserve user control

Users should be able to review, correct and reverse important actions where appropriate.

### 4. Accessible by default

Accessibility is part of the product experience, not a later enhancement.

### 5. Consistency

Similar actions and information should behave consistently across the product.
