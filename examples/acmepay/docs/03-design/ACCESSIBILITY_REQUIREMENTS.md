# acmepay — Accessibility Requirements

## Objective

Ensure the product can be used by people with a broad range of access needs.

## Requirements

- Semantic structure.
- Keyboard operability.
- Visible focus states.
- Appropriate labels and accessible names.
- Sufficient colour contrast.
- Screen-reader compatibility.
- Responsive text and zoom support.
- Error messages that are understandable and programmatically associated.

## Testing

Accessibility requirements must be included in relevant acceptance criteria and release testing.
