# acmepay — Product Principles

These principles guide product and engineering decisions.

## Principles

### 1. Solve the user problem first

Do not add functionality that does not materially improve the core user outcome.

### 2. Prefer clarity over complexity

The simplest understandable experience should usually win.

### 3. Trust must be earned

Explain important decisions and avoid misleading claims.

### 4. Security and privacy are product features

Do not treat them as post-release work.

### 5. Evidence over assumption

Measure behaviour, validate decisions and record meaningful findings.
