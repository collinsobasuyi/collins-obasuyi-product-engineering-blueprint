# acmepay — Quality Strategy

## Purpose

Define how quality is built into product delivery.

## Quality principles

- Test risk, not just features.
- Shift quality left.
- Automate where valuable.
- Keep critical user journeys covered.
- Accessibility and security are quality concerns.
- Production evidence matters.

## Quality dimensions

- Functional correctness
- Reliability
- Accessibility
- Security
- Performance
- Usability
- Maintainability
- Observability
